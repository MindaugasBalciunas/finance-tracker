# Finance Tracker

Personal finance tracking app — Go REST API + React dashboard.

## Tech Stack

| Layer | Tech |
|---|---|
| Backend | Go 1.22, Gin, GORM, SQLite |
| Docs | Swagger (swaggo) |
| Frontend | React 18, TypeScript, Vite, Tailwind CSS |
| Charts | Recharts |
| State | TanStack Query v5 |
| Forms | React Hook Form |
| Tests | Go `testing` + testify, Vitest + Testing Library |
| Docker | Docker Compose (backend + frontend + nginx) |

## Prerequisites

```bash
# macOS
brew install go node

# Install swag (Swagger codegen)
go install github.com/swaggo/swag/cmd/swag@latest
```

## Quick Start

```bash
cd finance-tracker

# Install all dependencies
make install

# Generate Swagger docs
make swagger

# Run backend (port 8080) + frontend (port 5173) in parallel
make dev
```

| URL | Description |
|---|---|
| http://localhost:5173 | React UI |
| http://localhost:8080/swagger/index.html | Swagger API docs |
| http://localhost:8080/api/v1/health | Health check |

## Running Tests

```bash
# All tests
make test

# Backend only
make test-backend

# Frontend only
make test-frontend
```

## API Overview

### Transactions  `/api/v1/transactions`

| Method | Path | Description |
|---|---|---|
| GET | `/transactions` | List with filters & pagination |
| POST | `/transactions` | Create expense / income / investment |
| GET | `/transactions/:id` | Get by ID |
| PUT | `/transactions/:id` | Update |
| DELETE | `/transactions/:id` | Delete |
| GET | `/transactions/summary` | Aggregated totals by type, category, month |

### Balances  `/api/v1/balances`

| Method | Path | Description |
|---|---|---|
| GET | `/balances` | List snapshots |
| POST | `/balances` | Add snapshot (total auto-calculated) |
| GET | `/balances/latest` | Most recent snapshot |
| GET | `/balances/trend` | Time-series for charts |
| GET | `/balances/allocation` | Pie chart breakdown |
| PUT | `/balances/:id` | Update |
| DELETE | `/balances/:id` | Delete |

### Query filters

```
date_from=2026-01-01&date_to=2026-03-31
type=expense|income|investment
category=Food
page=1&page_size=20
```
